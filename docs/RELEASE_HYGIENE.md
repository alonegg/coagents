# 命名与发布检查

状态：发布约束。

## 命名范围

产品显示名为 `CoAgents`，Web 入口称 `CoAgents Hub`。技术标识暂定为 `coagents`：CLI、MCP server ID、数据目录 `.coagents` 和环境变量前缀 `COAGENTS_`。这些位置必须同源生成或集中配置，包括包元数据、日志标识、配置注释、示例命令、UI 文案、安装与卸载说明。禁止把来源产品的名称、缩写、域名、图标、版权标识或专有命令作为默认值。

## 第三方材料隔离

原始网页、安装提示词、提取片段和二进制或打包脚本仅作独立归档的研究证据，不进入产品仓库、构建上下文、测试夹具、安装包或发布文档。新实现只根据这里的功能需求和自主设计接口编写。若未来引入任何第三方代码，必须先核对许可证并记录来源、版本及保留声明要求。

## 发布前检查

1. 扫描文件名、文本、压缩包内容、source map、包元数据、UI 资源、日志模板和生成配置中的旧标识与旧域名。
2. 检查网络请求与运行时依赖，确认默认状态不会连接来源服务；允许的外部地址由本产品配置显式列出。
3. 在空白机器环境安装、运行、卸载，检查磁盘路径、进程名和客户端配置残留。
4. 验证没有从参考归档复制的脚本、HTML、Prompt、图标或大段文案进入构建产物。
5. 保存扫描结果与手工验收记录；发现旧标识即阻止发布，修正后重新构建和检查。
6. 按 [PRD](PRD.md) 的三账户、两台独立机器、两种客户端完成团队验收；远程接入、实时通知、Git 交接、里程碑/截止日期和全文检索全部纳入第一版门槛。

自动检查要同时覆盖大小写、常见分隔写法和文件名。扫描规则应配置在内部发布流程中，避免把旧标识写进产品源码。当前产品工作区使用 CoAgents 名称；独立参考归档始终排除在构建范围外。
